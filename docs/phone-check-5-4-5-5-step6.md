# スマホ確認の手順（5-4・5-5・STEP 6）

確認用 URL：https://feature-field-mode.shrine-checklist.pages.dev （バージョン 2.0.0-dev.6）

所要時間は約30分です。途中（H）で**1時間以上あける**ところがあります。その間は待つだけで、ほかのことをしていてかまいません。

---

## 0. 準備

1. スマホの Chrome で確認用 URL を開く。
   - **期待**：一覧画面が出る。本番とは別の場所なので、本番の記録は出ない（空、または前にテストした記録だけ）。
2. 古い画面が残っていることがあるので、アドレスバー右の「⋮」→ 再読み込み（ぐるっと回る矢印）を押す。
3. **屋外か窓ぎわ**で行う（位置が取れないと天候の確認ができないため）。

---

## A. 一覧画面（バージョン）

4. 一覧画面のいちばん下を見る。
   - **期待**：「バージョン 2.0.0-dev.6」の横に「テスト版」と出る。dev.5 以前なら古い画面のままなので、手順2をもう一度。

## B. 設定画面（5-5：位置の丸め）

5. 一覧の下の「設定」を押す。
   - **期待**：「位置を約1kmに丸めて送る（おすすめ）」に**チェックが付いている**（最初からオン）。
6. 一覧に戻り「診断」を押して「■ 設定」の欄を見る。
   - **期待**：「位置の丸め（天候 API へ送るとき）: オン（小数2桁）」
7. 設定に戻ってチェックを外し、もう一度「診断」を見る。
   - **期待**：「位置の丸め（天候 API へ送るとき）: オフ」
8. 設定に戻って、**チェックを付け直す**（オンに戻す）。

## C. 現地モード（記録A を作る。オンラインのまま）

9. 一覧の「現地モードを始める」を押す。「前回の下書きを続けています」と出たら、横の「新しく始める」を押す。位置の許可を聞かれたら「許可」。
   - **期待**：「参拝 （今の日時）（日中など）」、位置の欄に精度（「±12m」など）、「天候：晴れ 18℃」のような表示。その下に「Weather data by Open-Meteo.com」のリンク。
10. **神社名は空のまま**にしておく（手順28で使う）。
11. 「写真を撮る」で1枚撮り、撮影直後に出るラベルの「**鳥居**」を押す。
    - **期待**：「ラベル『鳥居』を付けました。チェック『鳥居』も付けました」
12. もう1枚撮り、ラベルの「**手水舎**」を押す。
    - **期待**：「ラベル『手水舎』を付けました」だけ（チェックについての文は出ない）。
13. 3枚目を撮る。**ラベルは押さずに**次へ。
    - **期待**：ラベルを押さなくても続けて操作できる。
14. 「録音する」で5秒ほど録って止める。
15. 「メモを書く」で「テストのメモ」と入れ、「閉じる」。
16. 左上の「← 閉じる」を押す。

## D. 一覧画面（6-4：バッジ）

17. 今作った記録（名称未設定）を見る。
    - **期待**：「下書き」（赤いバッジ）と「写真3・音声1・メモ1」。0 の種類は出ない。

## E. 現地記録タブ（記録A を開く）

18. その記録を押して開く。
    - **期待**：神社名の下に「この記録は現地モードの下書きです…」の枠と「記録として確定」ボタン。「現地モードの記録」欄に、写真3枚のサムネイルとラベル名（鳥居／手水舎／ラベルなし（タップで選ぶ））、録音1、メモ1の全文。
19. 録音の「▶ 再生」を押す。
    - **期待**：音が再生される。
20. メモの行を押し、文を少し書き足して「閉じる」。
    - **期待**：欄のメモが書き足した文に変わる。
21. 下の「撮影チェック」欄を見る。
    - **期待**：「鳥居」にチェック。「現地モードの記録」欄のすぐ下に「自動チェックを取り消す」と「写真のラベルから自動で付けたチェック：鳥居（手で付けたチェックは外しません）」。
22. 撮影チェックの「**狛犬**」を指で押してチェックする。
23. 3枚目の写真（ラベルなし）を押して全画面で開き、ラベルの「**狛犬**」を押す。
    - **期待**：写真が大きく出て、「ラベル『狛犬』を付けました」だけ（狛犬は既に付いているため）。「閉じる」を押す。
24. 2枚目の写真（手水舎）を全画面で開き、ラベルを「**拝殿・本殿**」に変える。続けて「ラベルを外す」を押し、閉じる。
    - **期待**：変えた時点で「チェック『拝殿・本殿』も付けました」。ラベルを外しても、撮影チェックの「拝殿・本殿」は**付いたまま**。一覧の行は「ラベルなし（タップで選ぶ）」。
25. 「自動チェックを取り消す」を押し、確認で「OK」。
    - **期待**：「鳥居」と「拝殿・本殿」が外れ、**「狛犬」は残る**。ボタンが消え、「外しました：鳥居・拝殿・本殿」。
26. 「このタブをリセット」を押し、確認で「OK」。
    - **期待**：参拝日・時間帯・天候・チェックがすべて空になる。「現地モードの記録」欄の写真・録音・メモは**残っている**。
27. 「自動値を入れ直す」を押す。
    - **期待**：「入れました：参拝日・時間帯・天候」。3つの欄に値が戻り、それぞれ「自動」バッジ。
28. 「記録として確定」を押す。
    - **期待**：「神社名が空のまま確定します…よろしいですか？」と聞かれる。一度「キャンセル」→ 何も変わらない。もう一度押して「OK」→ 枠が消え「記録として確定しました」。

## F. 一覧画面（6-4：確定のあと）

29. 「← 一覧に戻る」を押す。
    - **期待**：記録A の「下書き」バッジが消え、「写真3・音声1・メモ1」は残っている。

## G. 機内モード（5-4：通信が戻ったら自動で取得）

30. **機内モードをオン**にする（画面上から下へスワイプ → 飛行機のマーク）。
31. 「現地モードを始める」を押し、神社名に「テストB」と入れる。
    - **期待**：「天候：取得待ち（通信できるときに取得します）」。
    - 位置が取れず「位置が分からないため…」と出たら、「手で入力」で緯度 35.68・経度 139.76 を入れて「この位置にする」。そのあと「取得待ち」になる。
32. 現地モードを開いたまま、**機内モードをオフ**にする。
    - **期待**：数秒〜十数秒で、自動で「天候：晴れ 18℃」のような表示に変わる（ボタンを押さなくてよい）。
33. 「← 閉じる」を押す。

## H. 参拝から1時間以上あとの取得（5-4：参拝した時刻の値）

34. もう一度**機内モードをオン**。「現地モードを始める」→「新しく始める」を押し、神社名に「テストC」と入れる。
    - **期待**：「天候：取得待ち…」（位置が取れなければ手順31と同じく手で入れる）。
35. 「← 閉じる」を押し、**Chrome をタスク一覧から消して完全に閉じる**。機内モードをオフにする。
36. **1時間以上あけてから** Chrome で確認用 URL を開く。
    - **期待**：開いた時点で自動で取得される。テストC を開くと、天候の欄に値と「自動」バッジ。
37. 「現地モードを始める」を押す（テストC の続きになる）。
    - **期待**：「天候：…（参拝した時刻の値）」と、後ろに「（参拝した時刻の値）」が付く。「閉じる」を押す。

## I. 診断画面（5-5：天候の欄）

38. 一覧の「診断」を押し、「■ 天候」の欄を見る。
    - **期待**：「通信: オンライン」「現地モードの記録: 3件」「取得済み 3件（現在の値 2・参拝時刻の値 1・archive 0）」「取得待ち 0件…」「今すぐ取り直す対象: 0件」。前にテストした記録が残っていれば、その分だけ件数が増える。

## J. 後片付け（6-4：削除の確認）

39. 記録A を開いて「この神社を削除」を押す。
    - **期待**：「写真3枚・録音1本・メモ1件も削除されます」。「OK」で削除。
40. テストB・テストC も同じように削除する。
    - **期待**：写真などが無いので、「この神社の記録を削除します。元に戻せません。よろしいですか？」だけが出る。

---

## スマホでは確かめないもの

- 参拝から92日を超えた記録で archive を使う切り替えは、日数を待てないため対象外。PC の自動テスト（`tests/weather-past.test.mjs`）で確認済み。

## うまくいかなかったとき

手順の番号と、画面に出た文をそのまま控える。診断画面の「診断内容をコピー」で貼り付けると原因を探しやすい。
