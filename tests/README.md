# 自動テスト

`index.html` のうち、画面に触れない処理（`// ==== data-core:start ====` から `// ==== data-core:end ====` までの区間）を取り出して、Node で試す。

## 実行方法

Node.js 18 以上が必要（追加のインストールは不要）。リポジトリのフォルダで次を実行する。

```
node --test "tests/*.test.mjs"
```

最後に `fail 0` と出れば、すべて通っている。

## 中身

| ファイル | 内容 |
|---|---|
| `helpers.mjs` | `index.html` から data-core 区間を取り出す処理、localStorage の代わり（容量の上限も再現できる）、過去の版の形をした架空の記録 |
| `save.test.mjs` | 差分保存（STEP 3-1）：変更の当て方、2つの画面からの保存、壊れた保存内容・容量不足のときに書かないこと |
| `media.test.mjs` | メディアの集計（STEP 3-3）：種類ごとの件数、どの記録にも属さないメディアの数え方 |
| `migrate.test.mjs` | 移行処理（STEP 3-2）：v1→v2 の変換が追加だけであること、冪等、検証、バックアップ、容量不足・読み戻し不一致のときに元データを変えないこと、移行ログ |

## 決まり

- **実データは入れない。** テストに使う記録は、すべて架空のもの（`s_test…` の id、「テスト神社」の名前）にする。公開リポジトリのため。
- data-core 区間には、画面（`document`）に触れる処理を入れない。テストから取り出せなくなる。
- IndexedDB と画面の動きは Node では試せないので、PC の Chrome で確認する。
